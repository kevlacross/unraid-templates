# Ecowitt Share to MQTT — Unraid template

The Community Applications template is maintained in [templates/ecowitt-share-to-mqtt.xml](../templates/ecowitt-share-to-mqtt.xml). It uses the existing public application image `ghcr.io/kevlacross/ecowitt-share-to-mqtt:latest`.

Application source, configuration instructions and application support: https://github.com/kevlacross/ecowitt-share-to-mqtt

Template/packaging issues: https://github.com/kevlacross/unraid-templates/issues

This template was moved from kevlacross/ecowitt-share-to-mqtt-ca into this shared template repository. Container names, images, ports and persistent storage mappings are preserved. Existing installed containers do not need to be reinstalled or have their data moved.

The MIT license from the original Ecowitt template repository is retained in LICENSE. The Ecowitt icon is copied from that repository with its attribution retained. The application source repository remains separate from this collection of Unraid templates.
